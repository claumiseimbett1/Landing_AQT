# Montería Club Deportivo AquaTEN - Landing Page

Landing page oficial del **Club Deportivo AquaTEN** en Montería, Córdoba, Colombia. Sitio web diseñado para promover los servicios de aquafitness y natación para niños y adultos, eventos deportivos y facilitar el contacto con el club.

## 📋 Descripción

Página web moderna y responsive que presenta los servicios y actividades del Club Deportivo AquaTEN, incluyendo:

- **Aquafitness**: Clases de ejercicios acuáticos para todas las edades
- **Natación para Niños**: Programas de natación infantil
- **Natación para Adultos**: Clases para adultos de todos los niveles
- **Eventos Deportivos**: Información sobre el Championship Master Swimming
- **Ubicación**: Piscina Corales y Villaolimpica en Montería
- **Contacto**: Formulario de contacto y enlaces a redes sociales

## 🚀 Instalación y Configuración

### Requisitos Previos
- Servidor web (Apache recomendado)
- Navegador web moderno

### Pasos de Instalación

1. **Clonar o descargar el proyecto**
   ```bash
   # Si tienes Git
   git clone [url-del-repositorio]
   cd Landing_AQT
   ```

2. **Subir archivos al servidor**
   - Sube todos los archivos y carpetas a tu servidor web
   - Asegúrate de mantener la estructura de carpetas

3. **Configurar el dominio**
   - Actualiza las URLs en `index.html` (líneas 19, 23, 32, 48, etc.)
   - Reemplaza `https://aquaten.com` con tu dominio real
   - Actualiza las URLs en `sitemap.xml`

4. **Verificar permisos**
   - Asegúrate de que `.htaccess` esté habilitado en Apache
   - Verifica permisos de lectura para archivos y carpetas

5. **Probar el sitio**
   - Abre el sitio en un navegador
   - Verifica que todas las imágenes y videos carguen correctamente
   - Prueba la navegación y formulario de contacto

## 📝 Personalización

### Cambiar Colores
Los colores están definidos como variables CSS en la sección `<style>`. Busca `:root` y modifica las variables:
```css
:root {
    --primary-color: #00f0ff;
    --dark-color: #0b1039;
    --light-color: #f0f6ff;
    --secondary-color: #0b5079;
}
```

### Actualizar Contenido
- Edita directamente `index.html`
- Las secciones están claramente marcadas con comentarios
- Mantén la estructura HTML semántica

### Cambiar Imágenes
- Reemplaza archivos en la carpeta `images/`
- Mantén los mismos nombres de archivo o actualiza las rutas en `index.html`
- Optimiza las imágenes antes de subirlas
